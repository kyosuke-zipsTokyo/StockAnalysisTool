# StockAnalysisTool(株式リサーチナビ)

日本国内の上場企業を銘柄コード/名称で検索し、株価チャート・企業価値・IR/適時開示を1画面に集約するWeb
アプリです。あわせて、過去の値動きパターンに基づく **統計的な傾向(上昇/下落の頻度)** と
**統計的な参考価格レンジ** を提示します。PC・スマホどちらでも利用できるレスポンシブなNext.jsアプリです。

このリポジトリには2種類のページがあります。

- `/stocks/[code]` … **実データ版**。J-Quants API(株価・企業価値)とEDINET API(IR・適時開示)から
  実際の銘柄データを取得して表示します。APIキー未設定の場合はその旨を案内する画面になります。
- `/demo/[code]` … **デモ版**。すべて架空企業のサンプルデータで、ニュース・経営陣コメント・
  アナリスト見解を含むフル機能のイメージを確認できます(実データにはまだ無い項目の見本)。

## 使い方(ローカル起動)

```bash
npm install
cp .env.local.example .env.local  # APIキーを設定(下記「実データの設定」参照)
npm run dev
```

`http://localhost:3000` にアクセスし、トップページの検索ボックスに銘柄コード(例: `7203`)または
企業名の一部を入力してください。APIキー未設定でも `/demo/1201` などデモ銘柄は動作します。

## 実データの設定

### 1. J-Quants API v2(株価・企業価値)

J-Quants APIはV2で認証方式が「APIキー方式」に一本化されました(V1のメールアドレス/パスワード →
リフレッシュトークン → IDトークンという方式は廃止)。APIキー自体に有効期限はありません。

1. https://jpx-jquants.com/ で登録し、ダッシュボードでAPIキーを発行
2. 環境変数に設定

```
JQUANTS_API_KEY=your-api-key
```

無料プランは株価データが**最大12週間程度遅延**します。呼び出しは `lib/jquants.ts` が
`x-api-key` ヘッダーを付けて `/v2/...` エンドポイントを叩くだけのシンプルな構成です。

### 2. EDINET API(IR・適時開示)

「EDINET API仕様書(Version 2)」(金融庁)に基づく手順です。無料・即時発行です。

1. EDINET閲覧サイト(https://disclosure2.edinet-fsa.go.jp/ )を開き、
   「EDINET APIの利用登録はこちらから」の「ログイン」をクリック
2. 表示されたサインイン画面で「今すぐサインアップ」をクリック
3. メールアドレスを入力し、画像認証を解いて「確認コードを送信」
4. 届いたメールの確認コードを入力して「コードの確認」
5. パスワードを設定して「作成」(12文字以上、小文字/大文字/数字/記号のうち3種類以上)
6. 多要素認証(MFA)の電話番号を登録し、SMSまたは自動音声で確認コードを受け取り入力
7. 表示された「APIキー発行画面」で氏名・電話番号(所属は任意)を入力し「連絡先登録(Save)」
8. 画面に表示される**APIキー**をコピー

```
EDINET_API_KEY=your-edinet-api-key
```

※ ブラウザ(Microsoft Edge等)でポップアップがブロックされていると、APIキー発行画面が
開かないことがあります。その場合は `https://api.edinet-fsa.go.jp` をポップアップ許可サイトに
追加してください。

EDINETには「銘柄コードで検索する」APIが無く、日付ごとの提出書類一覧しか取得できません。そのため
`lib/edinet.ts` は直近30日分の一覧を取得して証券コードで絞り込んでいます(取得結果はプロセス内に
6時間キャッシュ)。PDFはブラウザに直接EDINETのAPIキーを渡さないよう、`/api/edinet/document/[docId]`
でサーバー側からプロキシしています。

環境変数はNetlifyの場合「Project configuration → Environment variables」で設定してください。

## デプロイ(Netlify)

本アプリはAPIキーを使ったサーバー側処理(Route Handlers)が必要なため、静的書き出し
(Netlify Drop等)では動作しません。**GitHubリポジトリとNetlifyプロジェクトをGit連携**し、
pushのたびにNetlifyのNext.js Runtimeでビルド・サーバーレンダリングされる構成にしてください。

1. Netlifyのプロジェクト画面 → 「Import from Git」(または「Link repository」)
2. このGitHubリポジトリを選択(ビルドコマンドは自動検出、`netlify.toml` に `npm run build` を明記済み)
3. 上記の環境変数(`JQUANTS_MAIL_ADDRESS` / `JQUANTS_PASSWORD` / `EDINET_API_KEY`)をNetlify側に設定
4. デプロイ後は push するだけで自動的に再デプロイされます

## 主な機能

- **検索**: 銘柄コード/企業名/セクター名でのインクリメンタル検索。実データはJ-Quantsの上場銘柄マスタを
  `app/api/companies/search/route.ts` 経由でサーバー側検索(`components/search-box.tsx`)
- **銘柄ダッシュボード**(`app/stocks/[code]/page.tsx`):
  - チャート(終値・5日/25日移動平均・出来高、`components/price-chart.tsx`)
  - **統計的な値動き傾向**: 現在のRSI・移動平均の位置関係と類似した過去の状態を系列内で検索し、
    その後N営業日でどれだけの頻度で上昇していたかを集計(`lib/stats.ts` の `computeTrendTendency`)。
    「この結果の根拠」として現在のRSI水準・移動平均の位置関係・類似ケースの件数を言語化して表示
  - **統計的な参考価格レンジ**: 過去のN営業日リターンの分布(平均・標準偏差)から算出したボラティリティベースの
    参考レンジ(`referenceRange`)
  - **企業価値**: J-Quants決算短信サマリ(EPS/BPS等)から概算したPER/PBR/ROE/時価総額/増収率
    (`lib/fundamentals.ts`)。算出できない項目は実在しない数値を埋めず「—」表示
  - **IR・適時開示**: EDINET提出書類一覧(直近30日、PDFリンク付き、`components/disclosures-section.tsx`)
- **注目銘柄(ウォッチリスト)**: `localStorage` ベースで銘柄を登録し、`/watchlist` で一覧確認
  (`lib/watchlist.ts`, `hooks/use-watchlist.ts`)。デモ銘柄と実銘柄は `demo:`/`real:` プレフィックスで
  区別し、コード番号の衝突による混同を防いでいます

## 「買う/売る」ではなく「統計的傾向」を提示する設計方針

投資助言(「買うべき」「売るべき」等の推奨)は、金融商品取引法上「投資助言業」の登録が必要になるリスクが
あるため、本ツールは意図的にそれを避けています。代わりに、

- 過去の類似パターン発生後、株価が一定期間後に**統計的にどの程度の頻度で上昇/下落していたか**
- ボラティリティに基づく**参考価格レンジ**(過去の分布から見た目安)

という、あくまで**過去データの統計的な記述**にとどめ、各所に免責文言
(`components/disclaimer-banner.tsx`、実データ版では画面下部の注意書き)を表示しています。

## 未対応のデータ(現時点)

ニュース・アナリスト見解・経営陣コメントは、契約ベースの情報源が必要なため実データ化していません
(`/demo/[code]` のみサンプル表示)。かぶたん・株ドラゴン・moomoo証券・日経電子版・四季報オンライン・
Bloombergなど個別サイトの直接スクレイピングは、各サイトの利用規約で禁止・制限されている可能性が高いため
実装していません。実データ連携を検討する際は、各サービスの公式API・提携(データ配信契約)の有無を
確認のうえ、規約に沿った方法を選定してください。

「注目銘柄のIR・株主総会・決算報告を定期的に分析するバックグラウンド処理」も未実装です(cronジョブ +
EDINET/ニュースAPIからの定期取得・要約生成を想定)。

## 重要な注意事項

- `/demo/[code]` に掲載されている企業名・ニュース・IR要約・経営陣コメント・アナリスト見解は
  **すべて架空のサンプルデータ**です。
- `/stocks/[code]` の株価・企業価値・IR/適時開示は実データですが、株価は無料プランのため
  **最大12週間程度遅延**しています。
- 「傾向確率」「参考レンジ」は過去データに基づく統計的な参考情報であり、将来の値動きを保証するものではなく、
  **投資助言・売買の推奨ではありません**。投資判断はご自身の責任で行ってください。
