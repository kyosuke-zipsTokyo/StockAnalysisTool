# StockAnalysisTool(株式リサーチナビ・デモ版)

日本国内の上場企業を銘柄コード/名称で検索し、ニュース・アナリスト見解・IR要約・企業価値・成長余地・リスク・
経営陣コメントを1画面に集約するWebアプリのMVP実装です。あわせて、過去の値動きパターンに基づく
**統計的な傾向(上昇/下落の頻度)** と **統計的な参考価格レンジ** を提示します。PC・スマホどちらでも
利用できるレスポンシブなNext.jsアプリです。

> **重要: 現状はすべてサンプル(架空)データによるデモです。** 実在の企業・人物とは一切関係ありません。
> 詳しくは下記「重要な注意事項」を参照してください。

## 使い方(ローカル起動)

```bash
npm install
npm run dev
```

`http://localhost:3000` にアクセスし、トップページの検索ボックスに銘柄コード(例: `1201`)または
企業名の一部を入力すると、銘柄詳細ページに遷移します。

## 主な機能

- **検索**: 銘柄コード/企業名/セクター名でのインクリメンタル検索(`app/page.tsx`, `components/search-box.tsx`)
- **銘柄ダッシュボード**(`app/stocks/[code]/page.tsx`):
  - チャート(終値・5日/25日移動平均・出来高)
  - **統計的な値動き傾向**: 現在のRSI・移動平均の位置関係と類似した過去の状態を系列内で検索し、
    その後N営業日でどれだけの頻度で上昇していたかを集計(`lib/stats.ts` の `computeTrendTendency`)
  - **統計的な参考価格レンジ**: 過去のN営業日リターンの分布(平均・標準偏差)から算出したボラティリティベースの
    参考レンジ(`referenceRange`)
  - 企業価値(時価総額・PER・PBR・ROE・配当利回り)と成長ポイント
  - リスク要因(重要度付き)
  - IR要約(決算ハイライト)
  - 経営陣コメント(決算説明会・株主総会等での発言要約)
  - アナリスト見解(強気/中立/弱気の分布、目標株価)
  - 関連ニュース(出典は「情報源の種類」の汎用ラベルで表示)
- **注目銘柄(ウォッチリスト)**: `localStorage` ベースで銘柄を登録し、`/watchlist` で一覧確認
  (`lib/watchlist.ts`, `hooks/use-watchlist.ts`)

## 「買う/売る」ではなく「統計的傾向」を提示する設計方針

投資助言(「買うべき」「売るべき」等の推奨)は、金融商品取引法上「投資助言業」の登録が必要になるリスクが
あるため、本ツールは意図的にそれを避けています。代わりに、

- 過去の類似パターン発生後、株価が一定期間後に**統計的にどの程度の頻度で上昇/下落していたか**
- ボラティリティに基づく**参考価格レンジ**(過去の分布から見た目安)

という、あくまで**過去データの統計的な記述**にとどめ、各所に免責文言
(`components/disclaimer-banner.tsx`)を表示しています。

## アーキテクチャ / データソースの差し替え方針

現在は `lib/companies.ts` に架空企業8社分のサンプルデータをハードコードし、`lib/price-series.ts` で
銘柄コードをシードにした決定論的な擬似OHLC系列を生成しています(同じ銘柄コードなら毎回同じ系列になります)。

実データに接続する場合は、`Company` 型(`lib/types.ts`)や `OHLC` 型(`lib/price-series.ts`)を
インターフェースとして、以下のような **データプロバイダ層** を追加する構成を想定しています。

| 領域 | 現状(デモ) | 将来の接続候補 |
| --- | --- | --- |
| 株価・チャート | 擬似生成(`generatePriceSeries`) | [J-Quants API](https://jpx-jquants.com/)(JPXグループ公式、利用規約に沿った有償/無償プラン) |
| IR・適時開示 | サンプル固定文 | [TDnet](https://www.release.tdnet.info/)・[EDINET](https://disclosure2.edinet-fsa.go.jp/) の公式配信・API |
| ニュース | サンプル固定文 | 契約ベースのニュースAPI(利用規約上、二次配信・スクレイピング可否を個別に確認) |
| アナリスト見解 | サンプル固定値 | 証券会社・情報ベンダー提供のコンセンサスデータ(要契約) |

**かぶたん・株ドラゴン・moomoo証券・日経電子版・四季報オンライン・Bloombergなど個別サイトの直接スクレイピングは、
各サイトの利用規約で禁止・制限されている可能性が高いため今回のMVPでは実装していません。** 実データ連携を
検討する際は、各サービスの公式API・提携(データ配信契約)の有無を確認のうえ、規約に沿った方法を選定してください。

「注目銘柄のIR・株主総会・決算報告を定期的に分析するバックグラウンド処理」についても、`/watchlist`
ページ内に将来構想として記載していますが、本MVPでは未実装です(cronジョブ + 上記データソースからの
定期取得・要約生成を想定)。

## 重要な注意事項

- 掲載されている企業名・ニュース・IR要約・経営陣コメント・アナリスト見解は**すべて架空のサンプルデータ**です。
- 株価チャートは実データではなく、統計計算の仕組みを示すための**合成(擬似)データ**です。
- 「傾向確率」「参考レンジ」は過去データに基づく統計的な参考情報であり、将来の値動きを保証するものではなく、
  **投資助言・売買の推奨ではありません**。投資判断はご自身の責任で行ってください。
